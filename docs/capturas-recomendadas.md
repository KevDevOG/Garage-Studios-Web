# Capturas Recomendadas para la Memoria 📸

Lista de capturas de pantalla sugeridas para documentar el proyecto de forma visual y profesional.

## 🌐 Parte Pública (Experiencia de Usuario)
1. **Home (Hero Section)**: Mostrar el diseño premium y el mensaje principal.
2. **Animaciones de Scroll**: Captura de elementos apareciendo mediante Framer Motion.
3. **Página de Servicios**: El catálogo con sus tarjetas y precios.
4. **Galería**: El grid de imágenes del estudio.
5. **Formulario de Reservas**: Mostrando el selector de fechas y horas.
6. **Validación de Disponibilidad**: Captura de un mensaje indicando que una hora no está disponible.
7. **Páginas Legales**: Pie de página con links a Aviso Legal, Cookies y Privacidad.

## 🔐 Panel de Administración (Backoffice)
8. **Dashboard Principal**: Vista general con los KPIs (Ingresos, Reservas, Pagos).
9. **Calendario**: Vista mensual/semanal con reservas confirmadas y bloqueos.
10. **Detalle de Reserva**: Modal o página donde se gestiona el estado de una cita.
11. **CRM de Clientes**: Listado con etiquetas y badges de "Recurrente".
12. **Ficha de Cliente**: Perfil detallado con notas internas e historial comercial.
13. **Módulo de Finanzas**: Listado de movimientos con colores para ingresos/gastos.
14. **Auditoría**: Lista de logs detallando acciones administrativas.
15. **Exportaciones**: Página de descargas con las tarjetas de Excel.

## 🛠️ Aspectos Técnicos y Backend
16. **Supabase Dashboard**: Vista de la tabla `reserva` o `audit_log`.
17. **Políticas RLS**: Captura de una política de seguridad en el panel de Supabase.
18. **Vercel Deployment**: Panel de control mostrando el dominio `garagestudios.es` y el estado del deploy.
19. **Resend**: Panel de emails enviados para confirmar la trazabilidad de notificaciones.
20. **Estructura de Carpetas**: El árbol de directorios del proyecto en VS Code.

## 📧 Comunicación
21. **Email de Confirmación**: Ejemplo de cómo recibe el cliente la confirmación de su cita.
22. **WhatsApp prellenado**: Captura del mensaje generado automáticamente al reservar.

---
*Nota: Se recomienda usar una herramienta de captura que permita añadir anotaciones o flechas para resaltar partes específicas en la memoria final.*
